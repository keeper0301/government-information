# 광고 심사와 검색 공개 분리

광고 승인 여부는 광고 표시를 결정하며 글의 검색 공개를 일괄 허용하지 않습니다.
복지·대출 목록과 뉴스 목록·상세·키워드의 검색 판단은 별도의 검색 검수 설정을 사용합니다.

블로그 검색 공개는 `lib/blog-search-reviews.json`의 검수 기록과 현재 제목·본문·검색 설명·질문답변이 일치할 때만 허용합니다.
본문을 고친 뒤에는 다시 원문을 확인하고 검수 기록을 갱신해야 합니다.
상세 페이지와 사이트맵은 같은 판단 함수를 사용합니다.

이번 추가 대상은 속초 응시료, 직업계고 연계 교육, 경기도민회 장학금, 대전 노란우산 장려금, 경기 청년 노동자 관련 글 5편입니다.
기존 4편과 합쳐 명부에는 9편이 있습니다.

검색 허용은 구글 색인 완료나 검색 순위 회복을 뜻하지 않습니다.
배포 후 각 글의 검색 허용 표시, 대표 주소, 사이트맵 및 안내 목록 연결을 확인합니다.
