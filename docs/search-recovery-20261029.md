# 검색 노출 복구 운영

광고 심사 설정은 광고 동작을 유지합니다. 광고 승인만으로 모든 글을 검색 공개하지 않습니다.

## 공개 기준

- 복지·대출: 기존 원문 대조 승인 설명이 현재 정책과 일치해야 합니다. 숨김·중복은 제외합니다.
- 블로그: `lib/blog-search-reviews.json`에 검수한 글의 내용 지문과 확인일을 기록합니다. 제목·본문·검색 설명·질문답변이 바뀌면 공개 대상에서 제외합니다.
- 대량 목록과 보조 화면은 계속 검색 제외 상태입니다.
- 사이트맵과 가이드의 검수 글 링크도 같은 검수 함수를 사용합니다.
- 이번 분리는 블로그·복지·대출과 공통 검색 제외 함수·사이트맵·검색 및 비교 경로 차단에 적용합니다. 뉴스 상세와 뉴스 키워드 목록의 기존 광고 심사 연동은 별도 검토 대상으로 남아 있습니다.

## 이번 교정

수원 새빛 청년존·제주 해피아이·철원 출산장려금·영천 전입지원금 4편의 원문·검색 설명·질문답변을 교정했습니다. 운영 자료 저장 후 다시 읽은 본문과 검수 지문의 일치를 확인했습니다. 블로그 주소는 유지합니다.

- 수원: https://housing.gg.go.kr/contents/177/view
- 제주: https://jeju.go.kr/lifecycle/policy/list.htm?act=view&page=4&seq=49
- 철원: https://www.cwg.go.kr/www/selectMinwonWebView.do?deptCode=DEPTF_40&key=55&minwonNo=462
- 영천: https://www.yc.go.kr/depart/transferSupport/write.do

수원은 2026년 5월 안내를 해설한 글이며 현재 모집 중이라고 표시하지 않습니다. 제주도 출생연도별 적용 여부를 확정하지 않습니다. 배포 전 운영 화면은 기존 검색 제외 상태입니다.

## 배포 검증

1. 네 상세 페이지의 응답 본문과 검색 설정이 일치하고 검색 허용인지 확인합니다.
2. 네 주소가 사이트맵에 포함되고 `/guides`에서 연결되는지 확인합니다.
3. 미검수 글과 기존 목록은 검색 제외 상태인지 확인합니다.
4. 광고 심사 상태와 광고 차단이 유지되는지 확인합니다.
5. 서치콘솔에서 표본 URL의 검사와 재수집 요청을 진행합니다. 검색 허용은 실제 색인 완료·순위 회복과 다릅니다.
6. 배포일 기준 14일·28일 후 해당 URL별 색인·노출·클릭을 비교합니다.

원본, 수정본, 저장 확인, 되돌리기 문장은 개인 작업 저장소의 `docs/reports/2026-10-29-search-console/`에 있습니다. 되돌리기는 이후 수정된 글을 덮어쓰지 않도록 수정 시각 조건을 유지합니다.
