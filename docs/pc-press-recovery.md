# 중랑·밀양 개인 컴퓨터 자동 수집

운영 서버에서 접속하지 못하는 중랑구와 밀양시의 공식 보도자료를 개인 컴퓨터에서 수집합니다. 기존 수집기와 저장 경로를 사용하며 지역당 최신 자료 10건을 확인합니다. 원자료를 저장하고 공개 발행은 기존 검토 절차를 따릅니다.

## 현재 예약

윈도우 작업 예약 이름은 `키피오 중랑·밀양 정책자료 수집`이며 한국 시간 매일 오전 9시 20분 실행합니다. 컴퓨터가 켜져 있고 현재 사용자가 로그인했으며 인터넷에 연결되어 있어야 합니다. 놓친 예약은 실행 가능한 때 보충하도록 설정했습니다.

실패하면 5분 간격으로 최대 두 번 재시도합니다. 중복 실행을 무시하고 실행 시간은 10분으로 제한했습니다. 일반 사용자 권한으로 실행하며 로그인 비밀번호를 저장하거나 컴퓨터를 강제로 깨우지 않습니다.

## 실행 파일과 결과

- `tools/pc-press-recovery.cjs`: 두 지역만 실행합니다. 연결 등록 누락·중복, 목록 없음, 수집 오류, 본문 누락·길이 미달을 실패로 알립니다. 이미 저장된 유효한 자료는 정상 중복으로 처리합니다.
- `tools/run-pc-press-recovery.ps1`: 환경 파일 위치·노드 실행 파일 위치·기록 폴더를 받아 수집기를 실행합니다. 한국어 결과를 기록하고 수집기의 종료 코드를 전달합니다. 윈도우 기본 실행 도구에서 한국어를 읽을 수 있도록 문자 형식 표시를 보존해야 합니다.
- 공통 수집 결과의 `invalidBodyCount`는 본문을 읽지 못했거나 250자 미만이어서 제외한 건수입니다. 정상 중복 건수와 구분하여 개인 컴퓨터 예약의 재시도 판단에 사용합니다.

작업 예약에서 마지막 결과 `0`이면 정상 종료입니다. 결과 기록은 예약에 지정한 기록 폴더의 `수집-날짜-시간.log`에 남습니다. 기록에 `invalidBodyCount`가 있으면 본문 오류 건수도 확인합니다.

## 유지할 설정

예약이 사용하는 사이트 작업 폴더, 기존 설치 도구 폴더, 환경 파일을 유지해야 합니다. 위치를 옮긴다면 예약의 실행 위치와 인수를 함께 바꿔야 합니다. 환경 파일은 비밀값이므로 저장소에 올리거나 기록 파일에 내용을 복사하지 않습니다.

사이트 배포만으로 다른 컴퓨터에 윈도우 예약이 등록되지는 않습니다. 현재 자동 수집은 예약을 등록한 개인 컴퓨터에서 실행됩니다.
