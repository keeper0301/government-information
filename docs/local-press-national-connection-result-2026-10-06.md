# 전국 시·군·구 연결 작업 결과

## 연결 범위와 변경

- 현재 지역 검색 목록의 229곳 모두 수집 등록부에 연결했으며 누락 검사는 0곳입니다.
- 경북 누락 14곳, 경남 누락 16곳, 중랑·강북·의정부·제주시·서귀포 경로를 추가했습니다.
- 인천 개편을 반영해 제물포·영종·검단을 연결하고 서구 수집 주소를 서해구로 변경했습니다. 폐지된 인천 동구의 별도 실행은 제물포 경로로 교체했습니다.
- 부산·보령·강원·충북·경북·충남·광주 남구의 목록 또는 본문 추출을 복구했습니다. 공통 새올 게시판의 부서명 제목 오인과 양양 제목 선택도 보완했습니다.
- 철원은 일반 요청으로 접속하기 어려워 기존 브라우저로 공식 첫 화면·목록·본문·한글 첨부를 읽도록 연결했습니다.
- 울진은 전문을 제공하는 공식 지원사업 공지로 연결했습니다. 보도자료 전문을 읽은 것으로 표시하지 않습니다.
- 인제·정선·사하의 첨부문서는 실제 노드 실행으로 정상 전문을 확인했으며 수집기 코드는 유지했습니다.

## 정기 실행

- 공용 등록부의 222개 경로를 여섯 묶음으로 분배했습니다. 광역청 수집, 기존 보조 경로도 포함된 수치이므로 지역 검색 단위 229와 다릅니다.
- 한국 시간 매일 09:00, 09:15, 09:30, 09:45, 10:00, 10:15에 실행하도록 설정했습니다.
- 각 묶음은 37개 경로이며 중복·누락 없이 배정됩니다. 기존 개별 지역의 최대 10글 수집 기준을 유지합니다.
- 기존 별도 브라우저 예약 수집 경로는 유지했습니다. 중랑·강북·의정부는 공용 정기 실행에도 연결하며 개인 컴퓨터 실행기는 예비용으로 남겼습니다.
- 원자료 저장과 공개 검수는 기존 규칙을 유지합니다. 이번 연결로 수집된 글을 자동 공개하지 않습니다.

## 실제 자료 확인

- 신규·변경·복구 51개 경로에서 운영 저장소에 자료를 저장하거나 중복 처리한 뒤 본문 250자 이상을 다시 읽었습니다.
- 제목·원문 주소·출처·게시일·본문 길이는 `local-press-storage-verification.json`에 기록했습니다.
- 철원은 최초 통합 저장 검사에서 첫 화면 접속 시간 초과가 반복됐습니다. 제한 시간 안에서 재시도하도록 보완한 뒤 최신 3글 실제 저장에 성공했습니다. 공식 사이트의 간헐적인 접속 실패는 계속 가능한 상태입니다.
- 전체 읽기 전용 점검은 당시 등록된 186개 경로를 대상으로 진행했습니다. 첫 글이 짧은 사진 설명이거나 빈 원문인 경우 여러 글로 다시 확인했습니다. 모든 지역에서 매번 새 글이 저장된다는 뜻은 아닙니다.

## 검사 결과

- 관련 검사: 74개 파일, 561개 검사 통과.
- 전체 검사: 3,212개 통과, 17개 선택 검사 제외, 기존 실패 3개.
- 기존 실패 3개는 변경 전 코드만 따로 가져와 실행해 동일하게 재현했습니다. 금정 첨부 요청과 네이버 게시 안전 검사에서 문자열 비교 실패, 발행 문장 검수 도구의 윈도우 실행 실패입니다. 이번 수집 연결과 관련 없는 구현은 수정하지 않았습니다.
- 타입 검사, 변경된 코드 81개 파일의 형식 검사와 추가 저장 확인 도구 검사, 배포용 파일 생성, 관리자·정기 실행 경로의 인증 검사를 통과했습니다.
- 철원 재시도 보완 후 관련 검사 19개, 타입 검사 및 배포용 파일 생성을 다시 통과했습니다. 최종 검사 근거는 `local-press-final-verification.json`입니다.
- 모든 신규 코드 파일은 200줄 이하입니다. 외부 도구 설치나 비밀값 변경은 하지 않았습니다.

## 배포 상태와 남은 확인

아직 커밋·업로드·배포하지 않았습니다. 따라서 위 229곳은 구현 연결률이며 운영 서버에서 모든 경로가 정상 실행됨을 뜻하지 않습니다.

사용자 승인 후 기존 원격 변경을 보존하여 통합하고 배포합니다. 이어 서버 환경에서 강북·철원 브라우저 실행과 여섯 정기 수집 묶음, 기존 별도 수집 경로의 실행 기록을 확인해야 운영 완료로 보고할 수 있습니다.

인천 개편의 공식 근거: [인천광역시 행정구역 안내](https://www.incheon.go.kr/IC01070101).

## 후속 확인 기록

철원은 연결당 12초·최대 2회, 브라우저 읽기 전체 80초 제한을 적용했습니다. 최종 실제 실행에서 목록 3건·저장 3건·오류 0건을 확인했고 저장된 본문도 다시 읽었습니다. 최종 기록은 `local-press-storage-verification.json`의 철원 항목을 따릅니다. 재시도가 있어도 매번 성공을 보장할 수는 없습니다.
