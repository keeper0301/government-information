# 정책뉴스 탐색·사진·관련 안내 운영 기준

## 지역과 다음 행동

- 공개 제목으로 지역을 확정하지 못할 때만 공식 원문의 장소·적용 범위를 확인한다. 사례·사진 촬영지·설문 지역은 대상 지역으로 사용하지 않는다.
- `region-evidence.ts`는 주제와 근거 문장을 함께 대조하고, 사용한 문장을 `classification.regionEvidence`에 보관한다. 근거가 없으면 ‘지역 범위 확인 중’으로 남긴다.
- `reader-context.ts`는 신청·모집·문의 주제에 맞는 가이드를 선택한다. 상세 화면은 가이드의 현재 공개 검수 상태를 다시 확인한다.
- 공식 창구는 원문에 정확한 주소가 있는 허용 목록만 연결한다. 관련 없는 기사에는 가이드나 신청 버튼을 강제로 붙이지 않는다.

## 일정 표시

- ‘안내 기간 내’는 원문에서 확인한 시작일·종료일 사이를 뜻한다. 오늘 영업·접수·예약이 가능하다는 뜻이 아니다.
- `schedule`에는 시작일·종료일과 원문 인용이 필요하다. 연도는 임의로 추정하지 않는다. 기존 세 일정은 원문과 기사에 명시된 연도를 직접 대조했다.
- 예정·추진 발표는 날짜가 지났다고 시행 중으로 바꾸지 않는다. 검증된 일정이 없는 글은 제목의 종료·예정 표현만 구분하며 나머지는 일반 소식으로 표시한다.
- 종료 행사와 온라인 별도 날짜가 함께 안내된 경우는 ‘여러 일정’이다. 작품명 ‘광무에서 융희까지’ 같은 ‘까지’ 표현을 날짜로 취급하지 않는다.
- 화면용 `editorial-news-status.ts`와 검색용 `editorial_news_reader_status`의 규칙을 함께 변경하고 경계일·잘못된 날짜·작품명 사례를 검사한다.

## 사진

- 동래온천·공산성·하이패스 주제에 서로 다른 자료사진을 연결한다. 공식 사진만 허용한 글의 제한은 유지한다.
- `editorial-news-place-images.ts`에 원본 출처·저작자·허가 조건·촬영 시기를 기록했다. 표시 크기 480·640·1200 너비의 압축 파일을 사용한다.
- 동래온천 사진은 저작자의 제한 없는 이용 허락, 공산성 사진은 CC0, 하이패스 사진은 저작자 표시·동일조건 변경 허락 3.0 조건이다. 화면에 출처와 조건, 크기·형식 변경 사실을 함께 표시한다.

## 검색과 페이지

- `search_editorial_news`는 숨김·보류·잘못된 공개 형식의 글을 제외하고 전체 공개 글을 검색한다. 최신 100편으로 제한하지 않는다.
- 검색어의 모든 단어를 제목·질문·핵심 답변·대상·기관·본문에서 찾는다. `%`와 `_`도 일반 문자로 취급한다.
- 한 페이지는 12편이다. 화면에는 카드에 필요한 정보만 보내고 전체 본문은 보내지 않는다. 편집 뉴스는 자동 발행 뉴스 뒤에 합산한다.
- 분야별 건수는 현재 검색어·지역·일정 조건에서 전체 결과를 센다. 페이지 변경은 검색 조건을 유지하고 조건 변경은 첫 페이지로 돌아간다.
- 조회 실패는 안내 문구와 함께 확인 가능한 편집 뉴스만 표시한다. 빈 검색 결과로 숨기지 않는다.
- 검색 함수는 서버 권한만 호출할 수 있다. 일반 방문자와 로그인 사용자에게 원문·검수 기록 조회 권한을 주지 않는다.

## 확인한 범위와 배포 순서

- 2026-10-19: 운영 자동 뉴스 31편 중 공개 대상 30편, 숨김 1편. 공개 대상 13편의 부가 정보만 보완했다. 지역 7편, 관련 가이드 5편, 공식 창구 2편, 확정 기간 3편이며 항목은 서로 겹친다.
- 관련 시험 37개 파일·558개 항목, 타입·코드 형식 검사 통과. 모의 105편의 전체 검색·숨김/보류 제외·12편 제한·마지막 페이지를 저장소에서 확인했다.
- 실제 브라우저에서 검색·다음 페이지·일정 3편 필터·서로 다른 사진 3장·공식 창구와 가이드 연결을 확인했다.
- 검색 함수는 저장소에 적용했다. 화면과 앞으로 자동 발행되는 글의 새 지역·연결 규칙은 이 코드의 배포 이후 적용된다. 배포 후 실제 예약 발행 글을 별도로 확인해야 한다.
- 신규 코드에 대한 운영 배포, 전체 프로젝트 시험, 휴대전화 실제 기기 검사는 이 확인에 포함하지 않는다.
