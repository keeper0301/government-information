# 11월 1일 사진 보류 보완

정상 예약 실행에서 사진 부족으로 보류된 148974379, 148974473, 148974454, 148974391을 기준으로 사진 연결을 추가했다. 운영 기사나 발행 상태는 변경하지 않았다.

## 사진 근거

| 주제 | 자료사진 | 출처와 이용 조건 |
| --- | --- | --- |
| 전승공예품 | 국립중앙박물관 도자기, 2006년 | [tjfriese 원본](https://commons.wikimedia.org/wiki/File:Korean_pottery-01.jpg), 저작자 표시·동일조건 변경 허락 2.0 |

| 양육비 선지급 | 기존 계산기 자료사진 | 기존 촬영자·출처·이용 조건 유지 |
| 아동 보호 | 기존 나무 블록 자료사진 | 기존 촬영자·출처·이용 조건 유지, 병원이나 피해 아동 사진이 아니라는 설명 추가 |

새 원본은 1200·640·480 폭의 웹용 파일로 변환했다. 원본 출처·촬영자·촬영 연도·변경 내용·이용 조건을 표시하며, 도자기 변경본은 동일 이용 조건으로 제공한다. 실제 행사 출품작·결혼식 사진으로 설명하지 않는다.

## 검토 범위

- 공식 사진 전용 조건 뒤에 새 연결 규칙을 두어 해당 제한을 유지했다.
- 일반 결혼식, 병원 시설 확충, 도자기 산업 수출에는 새 사진을 임의 배정하지 않는다.
- 사진 연결은 본문 없는 목록에서도 동일하다. 사진 응답 검사는 기존 원본·480·640 경로를 계속 검사한다.
- 기존 미커밋 사진 개선은 보존했다. 이번 작업은 새 사진 2종과 기존 사진 2종의 주제 연결이다.

## 남은 확인

- 배포 후 실제 운영 사진 응답과 다음 정상 발행의 사진 검사 기록 확인이 필요하다.
- 148974379 초안은 10월 29일 종료 행사를 11월 1일에도 현재형으로 설명했다. 사진 연결만으로 본문 검수 완료 또는 공개 가능이라고 판정하지 않는다.
- 새 기사 공개, 수동 발행, 발행 한도 변경은 수행하지 않았다.
