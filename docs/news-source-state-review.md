# 정책뉴스 예정·검토 상태 보존

2026-10-19 학교 태양광 기사에서 체결 예고가 완료 사실로, 확대 여부 검토가 확대 전망으로 바뀐 문제를 보완했습니다.

- 생성 지침과 별도 내용 검사 지침 모두 예정·검토·완료를 문장별로 구분하도록 했습니다.
- `source-state.ts`는 협약 체결 예고 및 확대 여부 검토가 있는 원문에서 완료 단정·확대 전망 표현을 추가 검사합니다. 제목·질문·요약·대상·본문에 동일하게 적용합니다.
- 기존 초안 검사에 연결되어 실패하면 기존 한 번의 재작성을 거칩니다. 재작성 후에도 실패하면 공개하지 않습니다. 호출 횟수나 하루 발행 한도를 늘리지 않습니다.
- 직접 붙은 부정 설명은 구분합니다. 다른 문장의 부정이나 원문 문장의 일부만 빌려 검사를 통과할 수 없습니다.
- 여러 사업의 예정·완료가 섞인 원문에서는 서로 다른 사업의 근거를 잘못 빌리지 않도록 보수적으로 보류합니다. 정확한 바꿔쓰기라도 자동 검사에서 보류될 수 있으며, 별도 문맥 검토가 필요합니다. 모든 한국어 표현의 사실성을 보장하는 규칙은 아닙니다.

## 태양광 분류와 자료사진

태양광을 제목에 명시한 새 기사는 에너지로 분류합니다. 학교라는 단어만으로 교육 지원으로 분류하지 않습니다. 확인된 지역 근거가 없으면 미분류를 유지합니다.

자료사진은 Wikideas1의 2023년 12월 2일 촬영 사진입니다. [원본과 이용 조건](https://commons.wikimedia.org/wiki/File:Solar_panels_on_metal_roof.jpg)에서 상업적 이용·변경이 가능한 저작권 포기 조건을 확인했습니다. 웹용으로 크기와 형식을 변환했습니다. 촬영자·출처·이용 조건·해외 자료사진 표시를 제공합니다. 원문에 있는 별도 전재 금지 사진은 복사하지 않았습니다.

확인한 기존 기사와 새 태양광 제목에 자료사진을 연결합니다. 기존 공식 사진 전용 조건은 새 기사에서도 유지하며, 주제와 무관한 기사에는 이 사진을 넣지 않습니다.
