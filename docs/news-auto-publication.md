# 정책뉴스 자동 발행

자동 수집 자료에서 최근 7일 안의 공식 정책브리핑 상세 기사만 선택합니다. 한국 시각 오전 11시 10분, 오후 5시 10분에 실행하며 하루 최대 3편을 공개합니다. 하루 최대 6개 후보를 검사하고 한 실행은 240초 이내입니다.

원문 제목·발표일을 수집 내용과 대조하고 본문을 다시 읽습니다. 작성 글은 근거 인용문 존재, 숫자, 분량, 원문 복사와 반복 여부를 검사합니다. 별도 작성 도구 호출로 모든 사실과 독자에게 추가로 도움이 되는 내용을 대조합니다. 공개 직전에 원문을 다시 읽어 내용이 달라졌으면 보류합니다. 자동 검사는 사람 검수나 애드센스 승인을 보장하지 않습니다.

원문·비공개 근거·실패 사유는 관리자 서버 전용 `editorial_news_publications`에 저장합니다. 일반 사용자에게 저장소 접근 권한을 주지 않습니다. 공개 화면은 공개 상태의 글만 읽고 원래 수집 기사가 비공개되면 노출하지 않습니다.

자동 글에는 자동 작성·근거 대조 표시를 붙입니다. 기존 운영자 승인 글과 승인 기록은 보존합니다. 확인되지 않은 지역을 전국으로 추측하지 않으며 지역 범위 확인 중으로 분류합니다. 목록에는 최근 100개 자동 글과 기존 승인 글, 홈에는 최근 3개, 검색 제출 목록에는 공개 글 전체를 제공합니다. 오래된 상세도 번호로 직접 조회할 수 있습니다.

오류 후보는 보류하고 다음 후보로 진행합니다. 보류 자료는 하루 뒤 재시도합니다. 작업이 끊긴 예약은 10분 뒤 다시 처리할 수 있습니다. 저장할 때 예약 번호와 수집 자료의 수정 시각을 대조하여 다른 작업의 결과를 덮어쓰지 않습니다. 원문 기사 번호로 중복 공개를 막고 저장소 잠금으로 동시 실행의 하루 한도를 지킵니다.

원문 사진은 자동 복사하지 않습니다. 기존 지정 자료사진은 유지하며 새 자동 글에는 제목 주제에 맞춰 이용 허가를 확인한 자료사진을 선택합니다. 목록과 상세에 사진·촬영 연도·작성자·출처·이용 조건을 표시하고 기사 현장이나 대상 지역을 뜻하지 않는다고 안내합니다. 작은 압축 파일을 화면 크기에 맞춰 제공하며 사진 연결에는 추가 작성 호출이나 저장소 변경이 없습니다. 새 글은 작성 1회와 대조 1회로 처리하며 초안 검사 실패 시 작성 1회를 추가하여 바로잡고 같은 기준으로 다시 검사합니다. 근거 인용문은 원문 문장 번호로 선택하고 서버에서 원문 그대로 연결합니다. 작성 비용과 원문 접속 장애가 생기면 해당 후보를 보류합니다.

공식 사진만 사용하는 글은 목록에서 자료사진을 제외하고 상세에서는 공식 기사 사진 보기 링크를 제공합니다. 원문 사진은 사용 허락을 받기 전까지 복사하거나 재사용하지 않습니다.

## 운영 확인

예약 실행 경로는 `/api/cron/editorial-news-publish`입니다. 기존 예약 작업 비밀값 인증을 유지합니다. 실행 응답은 검사·공개·보류·충돌 건수와 공개 글 주소만 포함합니다. 키나 원문은 응답하지 않습니다.

배포 전 저장소 변경을 적용해야 합니다. 배포 후 인증 없는 예약 요청이 거절되는지, 공개 목록과 상세에 새 글·자동 확인 표시가 보이는지, 보류 본문이 노출되지 않는지 확인합니다. 예약 실행에서 공개한 글은 목록·홈·상세 저장을 갱신합니다.

검색 제출 목록은 한 시간마다 갱신하므로 새 글 반영까지 최대 한 시간 걸릴 수 있습니다. 작성 키가 없으면 후보 예약 전에 중단합니다. 설정 확인 과정에서 작성 도구를 호출하지 못한 후보는 하루 검사 한도를 소비하지 않고 다시 시도합니다.

초안 검사가 실패하면 정확한 보류 사유와 초안을 비공개 저장소에 남깁니다. 운영 복구 시 이미 검사한 같은 후보를 다시 시도할 수 있으며 새 후보 수는 하루 6개까지입니다. 중단·복구 재시도의 작성 호출 수는 후보 수와 다를 수 있습니다.

정책뉴스 작성·사실 대조는 `gpt-4.1-mini`를 사용합니다. 제목·질문·답변·대상과 본문의 모든 부분 각각의 사실 대조 및 정확한 원문 근거를 요구하며, 예정과 시행·가입과 신청을 혼동한 판정은 보류합니다. 다른 작업의 작성 도구는 바꾸지 않습니다.


## 독자 관점 글 품질

신청 안내·제도 변경·행사 및 사례를 구분해 기사에 맞는 제목과 본문 3~6개 부분을 작성합니다. 모든 부분을 질문형 제목으로 강제하지 않으며, 제도 변화·현장 내용·참가 사례를 일반적인 확인 조언으로 대체하지 않습니다. 원문 참가 사례는 원문 취재와 가명을 표시하고 키피오의 직접 인터뷰로 표현하지 않습니다. 부분별 최소 분량은 없으며 전체 글은 2600자 이내, 첫 답변은 180자 이내, 한 문단은 240자 이내입니다. 같은 구절 반복도 차단합니다.

사실 대조 외에 지원 대상 범위, 현재 이용 가능 여부, 구체적 효용, 가독성, 의미 중복, 원문의 핵심 내용 보존을 각각 검사합니다. 각 항목은 구체적인 판정 이유와 실제 초안의 해당 문장을 요구하며, 누락·실패·초안에 없는 판정 근거는 보류합니다. 본문이 늘어나면 모든 추가 부분도 개별 사실 대조해야 하며, 대조 번호의 누락·중복은 보류합니다. 통과한 품질 판정은 공개하지 않는 근거 저장소에 남깁니다. 활용할 핵심 정보가 없는 후보는 작성 재시도 없이 보류합니다.

이 검사도 작성 도구의 판단에 의존하는 부분이 있습니다. 자동 검사를 사람 검수로 표시하지 않습니다. 이미 공개한 글을 원문과 직접 대조해 정정하면 정정일과 내용을 표시하며 최초 자동 발행 기록은 유지합니다.
# 운영 서버에서 비공개 초안 검사

관리자는 `/admin/news/preview`에서 수집된 공식 기사 번호 9자리를 입력해 최신 작성·검사 기준을 실제 작성 도구로 시험할 수 있습니다. 원문과 초안·검사 근거가 관리자 화면에만 표시됩니다. 관리자 인증과 공식 주소·제목·발표일 확인을 거치며, 한 번에 기사 하나를 작성하고 최대 3회 호출합니다.

이 검사는 공개 저장, 기존 기사 수정, 발행 한도 사용, 보류 상태 변경을 하지 않습니다. 자동 검사 통과만으로 기사 품질을 보장하지 않으므로, 원문의 주요 변화·조건·사례가 보존되었는지 운영자가 별도로 대조해야 합니다. 작성 도구의 원래 오류와 인증 정보는 화면에 전달하지 않습니다.

공식 원문의 부제와 기사 안 사진 설명 문장도 사실 근거에 포함합니다. 사진 파일·배너 설명은 가져오지 않으며, 본문 자체의 최소 분량 검사는 유지합니다. 부제나 사진 설명의 시행일이 바뀌어도 원문 변경으로 판별합니다.

별도 검사 도구는 원문 근거와 초안 근거를 각각 문장 번호로 선택하며, 서버가 실제 문장을 연결합니다. 원문을 초안의 품질 근거로 대신 복사하거나 근거를 생략 표시로 이어 붙이지 않습니다. 검사 응답 예시는 실제 본문 개수에 맞추어 생성하고, 번호 누락·중복·범위 밖 선택은 기존과 같이 보류합니다. 작성·재작성·별도 검사 최대 3회 한도는 유지합니다.

숫자 검사에서는 본문에 있는 숫자와 공식 기사에서 확인한 발표 연도만 인정합니다. 발표 연도를 본문 밖 숫자로 잘못 보류하지 않으며, 다른 연도·금액·날짜를 추가로 허용하지 않습니다. 시행 예정일은 핵심 답변 첫 문장과 해당 본문 모두에서 예정으로 표시합니다. 예정일의 확정 시행 단정, 지원 연령 연장을 연령 제한 폐지로 확대하는 설명, 원문에 없는 후속 공고 계획은 별도 사실 검사에서 보류합니다.
