# 전국 시·군·구 자동 수집 연결 작업

사용자 요청: 전국 연결 작업을 시작하여 빠진 지역과 중단 경로를 보완한다.

## 완료 기준

1. 현재 지역 검색 단위 229곳에 실행 가능한 수집 경로가 있어야 한다. 세종은 별도 기초단체가 없으며 광역청으로 수집한다.
2. 공식 게시판 목록에서 글 제목·날짜·원문 주소를 읽고 실제 본문 250자 이상을 확보한다.
3. 첨부파일 전용 글은 공식 첨부자료를 읽는다. 메뉴나 제목만으로 본문 길이를 채우지 않는다.
4. 등록과 매일 실행은 구분한다. 개인 컴퓨터 전용 수집기도 자동 실행 경로가 없으면 운영 완료로 세지 않는다.
5. 저장·중복 처리와 기존 공개 검수 규칙을 유지한다. 수집된 원자료를 자동 공개하지 않는다.

## 작업 묶음

- 경북: 누락 14곳의 공식 수집기와 검사 추가, 경북·충남 광역청 목록 추출 오류 복구.
- 경남: 누락 16곳의 공식 수집기와 검사 추가, 공통 새올 게시판 제목·본문 오류 확인.
- 수도권·제주: 중랑·강북·의정부 복구, 제주 두 행정시 수집 추가.
- 인천: 제물포·영종·검단 추가와 서해구 명칭·주소 변경. 폐지된 동구 자동 실행 교체.
- 통합: 등록부·실행기 연결, 수집을 여섯 묶음으로 나누어 시간 제한으로 인한 미실행 방지.

## 검증과 보고

- 정규 자동 검사는 저장된 짧은 예제 자료로 실행하고 외부 사이트 접속에 의존하지 않는다.
- 실제 접속 검사는 별도 선택 실행으로 결과를 남긴다. 검사만 통과해도 실제 수집 실패를 숨기지 않는다.
- 기존 경로 전체도 실제 읽기 전용 검사로 확인한다. 운영 저장소 대신 기록용 대역을 사용한다.
- 신규 저장 확인 후 변경 내역을 보여주고 사용자 승인 뒤에 커밋·업로드·배포한다.

## 공식 행정구역 근거

인천시는 2026년 7월 개편 후 제물포구·영종구·서해구·검단구 명칭을 안내한다.

https://www.incheon.go.kr/IC01070101

## 진행 기록

- 인천의 현재 지역 목록과 폐지 구 오분류 방지 변경 작성.
- 서해구 최신 주소에서 실제 본문 세 건 확인.
- 여섯 수집 묶음의 중복·누락 방지와 예약 실행 설정 검사 통과.
- 전국 229개 지역 누락 검사 통과. 신규·복구 51개 경로 실제 본문 저장 및 재조회 확인.
- 관련 검사 561개, 타입 검사, 배포용 파일 생성 통과. 기존 전체 검사 실패 3개는 변경 전 코드에서도 재현.
- 철원 접속 안정성 보완과 운영 배포 전후 상태는 `local-press-national-connection-result-2026-10-06.md`에 기록.
