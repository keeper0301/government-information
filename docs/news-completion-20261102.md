# 정책뉴스 사진·경험·날짜 검사 보완

기본 운영 절차는 [자동 발행 안내](news-auto-publication.md)와 [발행 후 운영 점검](news-operations-followup.md)을 함께 따른다.

## 변경 내용

- 창덕궁 성정각 기사와 제목·검수된 요약에 해당 장소가 확인되는 신규 기사에 성정각 자료사진을 연결한다.
- 공식 사진 전용 기사는 새 자료사진 규칙을 적용하지 않는다.
- 원본 표시용 1200 화소 및 목록용 480·640 화소 파일을 함께 제공한다.
- 기자 개인 체험을 시민 전체 반응으로 확대하거나, 구매 가능 안내를 실제 구매 경험으로 바꾸는 확인된 표현을 초안 단계에서 보류한다. 제목·요약·소제목·본문을 검사한다.
- 작성 지침과 별도 내용 검수 지침에도 개인 경험의 주체와 실제 행동 보존을 요구한다.
- 점 표기 기간과 양쪽 연도가 명시된 연말 기간을 읽는다. 생략 연도는 발표월이 해당 기간 안에 있고 상대 연도 표현이 없을 때만 사용한다.
- 모든 본문 근거가 같은 행사 기간인 경우 날짜 없는 요약의 현재 이용 안내도 검사한다. 여러 행사나 날짜 없는 별도 근거는 전파하지 않는다.

## 확인 범위

검사는 추가 유료 호출 없이 기존 작성·재작성·별도 검수 흐름에 연결된다. 초안 단계 보류는 이후 사실·품질·사진 검사 통과를 뜻하지 않는다. 기존 검사 기록과 발행 한도는 바꾸지 않는다.

규칙은 확인된 표현과 날짜 형식을 보완한다. 모든 자연어 의미를 자동 보장하지 않으며, 연도가 모호한 기간이나 여러 행사 관계는 기존 사실 검수와 원문 직접 비교가 필요하다.

운영 적용 확인은 배포 후 정상 예약 실행으로 진행한다. 기존 글의 수동 수정이나 비공개 검사는 신규 자동 발행 성공으로 세지 않는다. 공개가 있으면 원문·본문·분류·사진 및 실제 검수 기록을 함께 확인한다.
