# 대표 글 5개 — 운영자 검토 자료

작성일: 2026년 10월 5일. 대표 글 다섯 개의 내용 승인이 완료되었습니다.

운영자가 아래 다섯 글의 내용을 승인했습니다. 승인자·승인 시각·본문과 출처의 버전 값을 별도 기록했습니다.
운영 사이트 배포와 코드 업로드는 별도 단계입니다.

## 1. 신청 서류 준비

- 해결하는 질문: 서류를 무엇부터 준비할까요?
- 핵심: 먼저 사업의 제출 목록을 확인하고 서류명·발급일·표시 항목을 적습니다.
- 자체 도움: 발급처·신청처를 구분하고 재발급을 줄이는 준비 순서입니다.
- 범위: 정부24 등본·초본 발급 안내는 사업별 선정 자격이나 필수 서류를 정하지 않습니다.
- [전체 본문](review/documents-before-government-benefit.md) · [정부24 직접 출처](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13100000015)

## 2. 정책자금 신청

- 해결하는 질문: 소상공인 정책자금 신청에서 어떤 차이를 먼저 볼까요?
- 핵심: 자금명과 직접·대리대출 유형부터 구분합니다.
- 자체 도움: 신청 기관·별도 보증·은행 심사·상환 비용·실행 기한의 비교 질문입니다.
- 범위: 특정 금리·승인 가능성·현재 접수 상태를 보장하지 않습니다. 기관 개요에 표시된 분기와 신청 당일 공지를 따로 확인합니다.
- [전체 본문](review/small-business-policy-fund-mistakes.md) · [소상공인시장진흥공단 직접 출처](https://ols.semas.or.kr/ols/man/SMAN018M/page.do)

## 3. 청년월세 사업 확인

- 해결하는 질문: 2026년 전국 신규 모집에 지금 신청할 수 있나요?
- 핵심: 2026년 신규 모집은 마감됐습니다. 다음 회차·서울시 사업과 구분해야 합니다.
- 자체 도움: 청년가구·원가구와 과거 지원 사업·누적 회차를 나눠 확인하는 순서입니다.
- 추가 보완: 이전 1차·2차 수혜자의 조건을 같은 규칙으로 읽지 않도록 설명했습니다.
- 범위: 다시 열리지 않은 국토교통부 자료와 본문 없이 응답한 동적 서비스 상세는 이번에 재확인했다고 기록하지 않았습니다. 열리는 복지로 공식 공지를 보완 출처로 추가했습니다.
- [전체 본문](review/youth-rent-checklist-2026.md) · [복지로 공식 공지](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/customer/notice/1309500_1141.html)

## 4. 근로장려금 신청 유형

- 해결하는 질문: 정기·반기 신청은 어떻게 구분하나요?
- 핵심: 직업 이름이 아니라 해당 귀속연도의 소득 종류를 먼저 봅니다.
- 자체 도움: 귀속연도·소득 종류·이미 신청한 유형을 정리하는 문의 메모입니다.
- 범위: 지급액 계산이나 현재 신청 가능 여부를 판단하지 않습니다. 안내문 수신도 지급 자격을 보장하지 않습니다.
- [전체 본문](review/geunjang-earned-income-tax-credit-check.md) · [국세청 직접 출처](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=238977&mi=40397)

## 5. 중복 지원 확인

- 해결하는 질문: 두 지원을 함께 받을 수 있는지 어디부터 확인할까요?
- 핵심: 두 사업의 기관·지역·회차와 제한 문구를 나란히 적습니다.
- 자체 도움: 동일 비용·기수혜자 제외·지원액 차감·변동 신고를 담당자에게 묻는 문안입니다.
- 범위: 복지로 소개는 검색 기능의 근거이며 모든 사업의 중복 허용 기준이 아닙니다.
- [전체 본문](review/policy-duplicate-benefit-limits.md) · [복지로 기능 안내](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html)

## 승인 기록

- 승인 범위: 대표 글 1~5번의 현재 본문과 출처·조건표.
- 승인 시각: 2026년 10월 5일 오후 1시 43분 6초, 한국 시간.
- 이후 본문이나 근거가 바뀌면 기존 승인으로 공개되지 않습니다.

청년월세 글은 마감된 모집의 안내이며 광고 대상으로 허용하지 않습니다.

내용 승인은 운영 사이트 배포나 코드 업로드와 별도로 기록합니다.
배포 직후와 배포 14일 뒤에 공개 글·검수 기록·근거 누락·검색 수집 상태를 다시 측정합니다.
