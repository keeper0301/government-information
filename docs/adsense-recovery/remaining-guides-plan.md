# 미검수 가이드 25개 정리

확인일: 2026년 10월 5일. 기존 내장 본문을 읽어 편집 방향을 정했습니다.
공식 출처가 확인됐다는 의미가 아니며, 실제 데이터베이스 본문과의 대조는 공개 적용 전에 수행합니다.

## 판단 기준

- 재작성: 한 질문으로 범위를 좁히고 기관의 사실과 키피오의 준비 방법을 분리합니다.
- 보류: 의료·돌봄·급여·금융 조건을 먼저 공식 자료와 대조해야 합니다.
- 통합: 같은 질문·같은 답인 경우에만 실행합니다. 이번에는 통합을 확정한 글이 없습니다.
- 새 출처 확인이나 초안 작성만으로 기존 공개 승인을 늘리지 않습니다.

재작성 대상 17개 중 3개는 운영자 내용 승인을 받아 코드 반영과 로컬 검증을 마쳤습니다. 나머지 14개는 대기이며, 8개는 근거 대조 전 보류입니다.
검색 노출·클릭 자료를 확보하지 못했으므로 아래 순서는 실제 수요 순위가 아니라 편집상 작업 순서입니다.

## 발견한 본문 문제

- “가장 흔한 실수”, “가장 어렵다”, “인기 있는 정책은 접수가 몰린다”는 표현에 통계 근거가 없습니다.
- 건강보험·소득·재산·위임 서류를 여러 사업의 공통 필수 자료처럼 읽을 여지가 있습니다.
- 한 문서에 여러 제도·상품의 조건을 섞으면 독자가 다른 사업에 같은 조건을 적용할 수 있습니다.
- 보조금24를 고정된 최신 메뉴 이름으로 설명한 글은 현재 정부24 화면과 대조가 필요합니다.

## 공개 적용과 측정

운영자가 본문을 검토하면 코드의 본문과 출처 기록에 그대로 반영하고, 내용을 묶은 승인 식별값을 생성합니다.
기존 공개 다섯 글의 승인을 유지하고 새 초안은 자동 승인하지 않는지 검사합니다.
승인한 변경 내용을 보여드린 뒤 변경 저장·업로드·배포를 진행합니다.
배포 직후 본문·검수 기록·검색 제출을 확인하고 배포 14일 뒤 검색 수집·노출·클릭을 비교합니다.
