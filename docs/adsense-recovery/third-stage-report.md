# 미검수 가이드 정리와 다음 세 글

후속 상태: 세 글은 내용 승인을 받아 코드 반영·로컬 검증을 마쳤습니다. 운영 배포는 대기 중이며 [반영 보고서](fourth-stage-report.md)에 최신 상태를 기록합니다. 아래는 초안 작성 당시의 보고입니다.

작업일: 2026년 10월 5일. 기존 공개 다섯 글의 승인 기록과 운영 코드는 변경하지 않았습니다.

## 진행 결과

- 미검수 25개 모두 본문을 읽고 편집 방향을 기록했습니다.
- 재작성 대상 17개 중 세 글의 검토용 본문을 완성했습니다. 나머지 14개는 대기입니다.
- 의료·돌봄·급여·금융 조건을 대조해야 하는 여덟 글은 보류합니다.
- 동일 질문과 답이라고 확정할 수 없어 통합이나 주소 이동은 하지 않았습니다.
- 실제 검색 수요 자료가 없어 작업 순서를 인기 순위라고 표현하지 않았습니다.

## 출처 확인

- 정부24 혜택알리미·자주 묻는 질문: 원본 문서에서 현재 메뉴와 이용 문의 구분 확인.
- 복지로 이용안내: 원본 문서에서 검색·신청·신청현황 기능 확인.
- 정책자금 화면: 원본 문서에서 상시접수·자금 소진 표시가 자금별로 다름을 확인.
- 복지로 청년월세 공지: 원본 문서에서 과거 2026년 신규 모집 종료 시각 확인.
- 복지로 모의계산·상담 안내: 원본 문서 조회에서는 동적 본문이 나오지 않아 실제 브라우저로 확인. 모의계산의 참고용 안내와 누리집 이용문의·보건복지 상담 구분을 확인했으며 개인정보 입력·계산·상담은 실행하지 않음.
- 별도 검토에서도 중요한 과장·중복·계획 누락은 발견하지 못함.

## 검증과 측정

- 목록 확인: 기존 미승인 25개와 문서의 25개가 제목별로 정확히 대응, 누락 없음.
- 분류 합계: 초안 세 개 + 재작성 대기 14개 + 보류 여덟 개 = 25개.
- 신규 문서 각각 200줄 미만.
- 실제 운영 사이트 재확인: 검색 제출 가이드 다섯 개, 검수 기록·공식 출처·본문 기준 통과 다섯 개.
- 운영 사이트 확인 기록은 에이전트 프로젝트의 `docs/reports/2026-10-05-keepioo-adsense-followup-check.json`에 저장.
- 공개 다섯 글의 다음 비교일: 2026년 10월 19일. 신규 글은 실제 배포 뒤 별도 기준선과 14일 후 비교일을 기록.
