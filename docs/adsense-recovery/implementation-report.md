- 승인 후 내용이나 출처가 바뀌면 기존 승인을 재사용하지 않습니다.
- 미검수 글은 홈·대상별 안내·블로그의 가이드 추천·관련 글·가이드 목록·검색용 주소 목록에서 제외합니다.

- 자료 조회 실패 시 오래된 내장 본문을 대신 공개하지 않습니다.
- 종료된 사업의 안내는 사람 검수 뒤 기록용으로 유지할 수 있지만 광고는 허용하지 않습니다.
- 근로장려금과 중복 지원 글을 질문별 설명·비교 항목·공식 출처로 보강했습니다.
- 기존 출처 대조 글 3개를 포함해 대표 5개 검토 자료와 전체 30개 검수 목록을 만들었습니다.
- 운영 사이트의 사람 검수 표시·직접 출처·공개 본문·검색 설정을 검사하는 도구를 만들었습니다.
