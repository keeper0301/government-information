# 지원사업 문의 전화 전, 어떤 질문을 준비할까요?

상태: 2026년 10월 5일 운영자 내용 승인 완료. 승인 본문을 코드에 반영했으며 운영 배포는 대기 중입니다.
기존 주소: `/guides/policy-application-call-script`.

## 집필 기준

- 질문: 로그인 오류와 지원 자격 질문을 같은 곳에 문의해도 될까요?
- 직답: 사이트 이용 문제와 사업 조건을 구분하고, 사업명·회차·헷갈리는 문구를 적어 문의하세요.
- 근거: 정부24의 이용 문의 안내, 복지로의 이용 문의·복지 상담 구분, 정책자금 공식 상담 경로.
- 하위 질문: 어디에 전화하나요? 어떤 정보를 먼저 말하나요? 통화하면 신청된 건가요?
- 관련 경로: [가이드 목록](https://www.keepioo.com/guides), [서류 준비](https://www.keepioo.com/guides/documents-before-government-benefit), [중복 확인](https://www.keepioo.com/guides/policy-duplicate-benefit-limits).

## 본문

사이트 이용 문제와 사업 조건을 구분하고, 사업명·회차·헷갈리는 문구를 적어 문의하세요. 로그인이나 파일 첨부 문제인지, 자격·서류·중복 조건 질문인지 나누면 확인할 창구를 고르기 쉽습니다.

### 먼저 문의 종류를 고르세요

정부24는 민원 신청·발급, 혜택알리미 이용, 회원가입·로그인 문의 항목을 구분합니다. 복지로도 누리집 이용문의와 보건복지 상담 경로를 따로 안내합니다. 특정 사업의 자격 질문은 해당 공고의 담당 부서·신청기관을 확인하는 것이 출발점입니다.

| 문의 종류 | 먼저 확인할 경로 | 키피오의 준비 메모 |
|---|---|---|
| 로그인·첨부·화면 오류 | 이용 중인 사이트 고객센터 | 화면 이름·오류 발생 시각·어떤 단계인지 |
| 대상·서류·신청기간 | 해당 사업 공식 공고의 문의처 | 사업명·기관·지역·회차·헷갈리는 문구 |
| 소상공인 정책자금 이용 | 정책자금 사이트 공식 상담 안내 | 자금명·직접 또는 대리대출·진행 단계 |

이 표는 확인 순서이며 모든 기관의 업무 분장을 확정하는 표가 아닙니다. 연결된 창구에서 담당 업무가 아니라고 하면 정확한 담당 기관을 물어보세요.

### 통화 전에 한 장만 준비하세요

사업명, 공고 주소, 모집 회차, 확인하려는 조건, 이미 진행한 단계를 한 줄씩 적으세요. 소득·재산의 정확한 금액을 묻기 전에 그 사업에서 어떤 기간과 가구 범위를 쓰는지 확인할 수 있습니다. 키피오에 신분증이나 계좌 내역을 첨부할 필요는 없습니다.

### 그대로 바꿔 쓸 수 있는 문의 예시

아래는 실제 상담 사례가 아닌 키피오의 예시 문안입니다.

> “[사업명·지역·회차] 공고를 보고 문의드립니다. [대상 설명의 문구]가 제 상황에 어떻게 적용되는지 확인하고 싶습니다. 어느 기준일의 어떤 자료를 확인해야 하나요? 필요한 서류의 정확한 이름과 제출 경로도 알려주실 수 있나요?”

중복 지원이 문제라면 받는 사업명·기간을 따로 적고 “동시 수령 제외인지, 금액 차감인지, 기존 지원 종료 후 신청인지”를 물어보세요. 답변이 없는 항목은 확인 필요로 남겨두세요.

### 통화 뒤에는 범위를 기록하세요

통화일, 담당 부서, 안내받은 공고·회차, 다시 확인할 자료를 적으세요. 다른 기관이나 다음 회차에도 같은 답이 적용된다고 가정하지 마세요. 담당자의 구두 안내와 공고가 다르게 보이면 어떤 공고나 정정 안내를 기준으로 해야 하는지 추가로 확인하세요.

### 상담과 신청 완료를 구분하세요

통화 메모만으로 접수가 완료됐다고 판단하지 마세요. 공식 제출 경로에서 신청 상태나 접수 내역을 확인해야 합니다. 복지로 이용안내는 상담성 정보와 별개로 서비스 신청현황 확인 기능을 안내합니다. 신청 가능 안내도 최종 선정을 보장하지 않습니다.

## 공식 출처와 확인 범위

- [정부24 자주 묻는 질문과 공통 고객센터 안내](https://plus.gov.kr/portal/faq/): 이용 문의 구분. 특정 지원사업의 선정 권한을 의미하지 않음.
- [복지로 공식 시작 화면](https://www.bokjiro.go.kr/ssis-tbu/index.do): 모바일 시작 주소에서 이 화면으로 이동하는 것을 확인하고, 브라우저 하단에서 누리집 이용문의와 보건복지 상담 안내를 대조함. 상담 결과를 직접 검증한 자료가 아님.
- [소상공인 정책자금 공식 안내](https://ols.semas.or.kr/ols/man/SMAN010M/page.do): 정책자금 상담 경로. 개인의 대출 자격·접수 상태를 판정하지 않음.
- [복지로 이용안내](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html): 서비스 신청현황 확인 기능.

변경 이유: 범용 자격 예시를 실제 상담 사례처럼 보이지 않게 바꾸고, 문의 종류·통화 기록·접수 확인을 나눴습니다.
