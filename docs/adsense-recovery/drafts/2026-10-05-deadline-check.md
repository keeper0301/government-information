# 지원사업 마감일, 날짜 말고 무엇을 확인할까요?

상태: 2026년 10월 5일 운영자 내용 승인 완료. 승인 본문을 코드에 반영했으며 운영 배포는 대기 중입니다.
기존 주소: `/guides/deadline-policy-not-missing`.

## 집필 기준

- 질문: 지원사업 마감일만 달력에 넣으면 충분할까요?
- 직답: 날짜와 함께 종료 시각·접수 방식·예산 소진 조건을 기록하고, 제출 뒤 접수 상태를 확인하세요.
- 근거: 정책자금 공식 화면의 상시접수·자금 소진 표시, 마감된 청년월세의 실제 종료 시각, 복지로 신청현황 안내.
- 하위 질문: 상시접수는 무조건 계속 열리나요? 며칠 전 알림을 정해야 하나요? 파일을 올리면 신청된 건가요?
- 관련 경로: [가이드 목록](https://www.keepioo.com/guides), [서류 준비](https://www.keepioo.com/guides/documents-before-government-benefit), [마감된 청년월세 모집](https://www.keepioo.com/guides/youth-rent-checklist-2026).

## 본문

마감 날짜와 함께 종료 시각·접수 방식·예산 소진 조건을 기록하세요. 신청 당일 공식 접수 상태를 다시 보고, 제출 뒤에는 접수 내역이나 처리 상태를 확인해야 합니다.

### 날짜만 적으면 빠지는 조건

공고에서 사업명·지역·모집 회차와 접수 시작·종료 날짜를 먼저 찾으세요. 종료 시각, 방문·온라인·우편의 제출 기준이 따로 있는지도 확인하세요. 적혀 있지 않으면 자정 마감이나 우편 발송일 기준으로 단정하지 말고 공식 문의처에서 확인하세요.

### 상시접수와 예산 소진은 다릅니다

2026년 10월 5일 소상공인 정책자금 화면에는 상시접수 표시와 ‘자금 소진 시까지’ 표시가 각각 보입니다. 서로 다른 자금의 표시를 하나의 종료 규칙으로 합치지 마세요. 이 글은 어떤 자금이 신청 시점에도 접수 중인지 보장하지 않습니다. 관심 있는 자금의 개별 공고와 최신 접수 화면을 다시 확인하세요.

### 키피오의 일정 메모 양식

아래는 개인 일정 정리를 돕는 양식입니다. 기관의 접수 규칙을 대신하지 않습니다.

| 적을 항목 | 개인 메모 |
|---|---|
| 사업명·기관·지역·회차 | 정확한 공고 이름과 주소 |
| 공식 시작·종료 시각 | 공고에 없으면 확인 필요 |
| 종료 조건 | 날짜 종료·예산 소진·상시 표시를 구분 |
| 제출 방법과 완료 기준 | 공식 공고나 담당자에게 확인한 내용 |
| 준비할 서류와 예상 준비일 | 본인의 준비 상황에 맞게 적기 |
| 마지막 접수 상태 확인일 | 확인 시각과 공식 화면 주소 |
| 제출 결과 | 접수 번호·신청 상태 등 공식 확인 내역 |

### 알림은 준비 시간에 맞춰 정하세요

서류 발급·인증·문의에 필요한 시간을 먼저 적고, 그 일정에 맞춰 준비 시작과 제출 후 확인 알림을 잡으세요. ‘7일 전·3일 전’이 모든 사업의 공식 기준은 아닙니다. 예산 소진형이라면 달력의 예정 마감일만 믿지 말고 준비 중에도 공식 접수 상태를 확인하세요.

### 마감된 공고를 다음 회차에 적용하지 마세요

복지로의 2026년 청년월세 공지는 신규 접수 종료를 5월 29일 16시로 안내했습니다. 현재 날짜에는 그 회차가 마감된 과거 안내입니다. 다음 모집이 열려도 날짜·조건이 같다고 가정하지 마세요. 옛 신청 주소가 열리는 것과 현재 접수 중이라는 사실도 구분해야 합니다.

### 제출 결과를 확인하세요

서류를 준비하거나 첨부하는 단계와 접수 완료 상태를 나눠 확인하세요. 복지로는 공식 이용안내에서 신청현황 조회 기능을 설명합니다. 접수 확인은 선정을 뜻하지 않습니다. 예산·자격·서류 심사 결과는 해당 사업의 공식 안내를 확인하세요.

## 공식 출처와 확인 범위

- [소상공인 정책자금 접수 화면](https://ols.semas.or.kr/ols/man/SMAN010M/page.do): 조회 당시 상시·자금 소진 표시. 전체 지원사업의 공통 규칙이 아님.
- [복지로 2026년 청년월세 공지](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/customer/notice/1309500_1141.html): 과거 신규 접수의 종료 날짜·시각. 현재 모집이나 다음 회차의 기준이 아님.
- [복지로 이용안내](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html): 신청현황 확인 기능.

변경 이유: 근거 없는 접수 혼잡 표현과 고정 알림 규칙을 걷어내고, 공식 종료 조건과 개인 준비 일정을 분리했습니다.
