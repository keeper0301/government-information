# 정부24 혜택알리미와 복지로, 어디서 먼저 찾을까요?

상태: 2026년 10월 5일 운영자 내용 승인 완료. 승인 본문을 코드에 반영했으며 운영 배포는 대기 중입니다.
기존 주소: `/guides/bokjiro-vs-gov24-difference`. 주소를 바꾸지 않고 제목·본문을 갱신할 계획입니다.

## 집필 기준

- 질문: 정부 혜택을 찾는 것과 복지서비스를 신청하는 것은 어디서 시작할까요?
- 직답: 혜택을 넓게 찾으려면 정부24 혜택알리미, 복지서비스 정보를 찾고 신청 경로를 확인하려면 복지로에서 시작하세요.
- 근거: 현재 정부24 혜택알리미의 간편찾기·전체 혜택 메뉴, 복지로의 서비스 검색·신청·진행현황 안내.
- 하위 질문: 옛 보조금24 설명과 현재 메뉴가 다른가요? 검색 결과면 선정된 건가요? 두 곳의 사업명이 다르면 어떻게 확인하나요?
- 관련 경로: [가이드 목록](https://www.keepioo.com/guides), [서류 준비](https://www.keepioo.com/guides/documents-before-government-benefit), [중복 확인](https://www.keepioo.com/guides/policy-duplicate-benefit-limits).

## 본문

혜택을 넓게 찾으려면 정부24 혜택알리미, 복지서비스 정보를 찾고 신청 경로를 확인하려면 복지로에서 시작하세요. 어느 사이트에서 찾았든 신청할 사업의 공식 상세에서 대상·기간·제출처를 다시 확인해야 합니다.

### 예전 보조금24 설명을 보고 왔다면

2026년 10월 5일 정부24 화면에서 확인한 메뉴 이름은 ‘혜택알리미’입니다. 기존 정부24 시작 주소는 새 정부24 화면으로 이동합니다. 이 글에서는 현재 확인되는 ‘간편찾기’와 ‘전체 혜택’을 기준으로 설명합니다. 옛 안내에 있는 버튼 이름을 그대로 찾기보다 현재 메뉴를 확인하세요. 로그인 뒤 맞춤 조회 과정은 이번에 직접 검증하지 않았습니다.

### 복지로에서는 무엇을 확인하나요?

복지로 공식 이용안내에는 복지서비스 검색, 모의계산, 서비스 신청, 신청현황 확인이 구분되어 있습니다. 찾은 서비스의 상세에서 온라인 신청 경로가 있는지 확인하세요. 모든 사업이 같은 온라인 절차로 신청된다고 가정하지 마세요.

### 두 곳의 결과를 비교하는 표

아래 표는 키피오가 제안하는 개인 메모 양식입니다. 사이트 기능이나 기관의 선정 기준이 아닙니다.

| 적을 항목 | 정부24에서 찾은 내용 | 복지로에서 찾은 내용 |
|---|---|---|
| 정확한 사업명 | 직접 적기 | 직접 적기 |
| 기관·지역·모집 연도 | 직접 적기 | 직접 적기 |
| 대상 설명의 원문 주소 | 직접 적기 | 직접 적기 |
| 신청 시작·종료 시각 | 없으면 확인 필요 | 없으면 확인 필요 |
| 신청처와 제출 방법 | 직접 적기 | 직접 적기 |
| 마지막으로 확인한 날짜 | 직접 적기 | 직접 적기 |

### 검색 결과와 선정 결과를 구분하세요

복지로 모의계산 안내는 입력 자료에 따른 참고 결과와 신청 후 공적자료 조사에 따른 실제 선정을 구분합니다. 포털에 사업이 보이거나 모의계산이 유리하게 나왔다고 선정된 것은 아닙니다. 신청 완료 여부도 별도로 확인해야 합니다.

### 사업 이름이 비슷할 때

기관·지역·연도를 먼저 비교하세요. 이 세 항목이 다르면 같은 조건을 옮겨 적용하지 마세요. 신청할 공식 상세를 저장한 뒤 서류 준비와 중복 지원 문의에 사용하세요. 주민등록번호나 소득 자료를 키피오에 보내는 과정은 필요하지 않습니다.

## 공식 출처와 확인 범위

- [행정안전부 정부24 혜택알리미](https://plus.gov.kr/portal/benefitV2/): 공개 메뉴·현재 표시 이름만 확인. 로그인 후 맞춤 조회·선정 여부는 확인하지 않음.
- [복지로 이용안내](https://www.bokjiro.go.kr/ssis-tbu/cms/pc/intro/intro/info/01/index.html): 검색·신청·신청현황의 기능 설명. 특정 급여의 자격 기준이 아님.
- [복지로 모의계산 안내](https://www.bokjiro.go.kr/ssis-tbu/twatbz/mkclAsis/mkclPage.do): 브라우저에서 안내 문구를 확인해 참고 계산과 실제 선정의 구분을 대조함. 계산을 직접 실행하지 않음.

변경 이유: 오래된 메뉴 설명을 갱신하고 검색·계산·신청·선정을 구분했습니다.
