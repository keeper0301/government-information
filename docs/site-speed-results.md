# 사이트 속도 개선 결과

작성일: 2026년 10월 6일

## 바꾼 내용과 이유

1. 비로그인 방문자에게 필요 없는 추천 100건 조회를 없앴다. 정책 카드에 표시하는 항목만 읽으며, 로그인 추천에 필요한 정보는 별도로 유지한다.
2. 공개 통계와 정책 목록을 60초 동안 재사용한다. 사용자별 추천은 공통 저장하지 않는다. 조회 실패를 빈 목록이나 0건으로 저장하지 않는다.
3. 홈 상단 안내는 저장소 조회를 기다리지 않고 먼저 보여준다. 지도와 가이드는 준비되는 대로 이어서 표시한다.
4. 지역 지도와 하단의 많은 링크가 방문 전에 다른 화면을 미리 읽는 일을 줄였다. 지역 버튼 이동과 누름 효과는 유지한다.
5. 뉴스 카드 사진을 화면 크기에 따라 약 40킬로바이트 또는 66킬로바이트 파일로 표시한다. 기존 원본은 약 309킬로바이트이며 사진 출처와 이용 조건을 유지했다.
6. 검수 기록이 있는 가이드만 먼저 조회한다. 본문이 바뀌면 검수 판정이 즉시 달라져야 하므로 검수 결과 자체는 요청 간 저장하지 않는다.
7. 공개 뉴스 목록의 로그인 확인 대기를 분리했다. 숨김 글과 개인 화면의 접근 제한은 유지한다.
8. 큰 오류 기록 도구를 첫 화면 뒤에 읽는다. 준비 전에 발생한 오류는 임시 처리기를 통해 기록 도구로 전달한다.
9. 서비스워커는 정적 파일만 재사용한다. 개인 화면과 화면 전환 자료는 저장하지 않고, 네트워크 실패 때 오프라인 안내를 표시한다. 파일 저장 실패가 정상 응답 전달을 막지 않도록 보완했다.
10. 최신 수집 시간을 찾는 운영 저장소 색인 3개를 적용했다. 공개 홈·복지 목록·뉴스 목록에 서울 실행 지역을 지정했다.

## 실제 검사 결과

- 전체 자동 검사: 3,272개 통과, 18개 제외, 실패 없음. 검사 파일 527개 통과, 4개 제외.
- 변경 파일 코드 형식 검사, 자료형 검사, 배포용 빌드 통과.
- 별도 코드 검토에서 발견한 문제 3개 수정: 추천 카드 표시 정보, 오프라인 대체 화면, 저장 실패 시 정상 파일 전달. 각각 실패를 재현한 검사와 수정 후 통과를 확인했다.
- 최종 적대적 검토에서 추가 2개 문제 수정: 잘못된 페이지 번호의 화면 오류, 브라우저 저장소 접근 실패의 정상 파일 전달 중단. 새 회귀 검사 9개 실패를 확인하고 수정 후 관련 검사 22개가 통과했다. 독립 소스 재검토도 완료했다. 외부 유료 검토는 실행하지 않았다.
- 브라우저 확인: 휴대폰 너비 홈과 지역 지도 표시, 서울 버튼 클릭 후 서울이 선택된 정책 목록 표시, 뉴스의 작은 사진 실제 읽기, 출처·이용 조건 표시.
- 비로그인·빈 프로필의 추천 조회 제거, 필터별 저장 구분, 조회 실패 처리, 변경된 가이드 숨김, 개인 화면 저장 제외는 자동 검사로 확인했다.
- 실제 로그인 계정으로 추천을 사용하는 검사는 실행하지 않았다.

휴대폰 측정 조건은 화면 390×844, 통신 지연 150밀리초, 다운로드 초당 200,000바이트, 처리 속도 4배 지연, 브라우저 저장 끄기와 서비스워커 우회였다. 기존 운영 홈의 첫 내용 표시 2.804초·문서 읽기 완료 8.160초와 실행 장소가 달라 단순 개선율을 계산하지 않는다. 로컬 측정은 운영 서버 응답 지연을 포함하지 않는다.

기존 운영 서버는 미국, 저장소는 서울에서 실행되고 있었다. 서울 지역 설정의 실제 배포 반영과 효과는 배포 후 확인해야 한다. 오류 기록 도구 지연 읽기는 첫 화면의 자동 성능 기록 시작 시점을 바꾸므로 운영 오류 기록도 확인한다.

## 반영 상태와 다음 확인

- 운영 저장소 색인: 적용 완료. 자료 내용과 접근 권한은 변경하지 않았다.
- 사이트 코드: 구현·검사 완료. 커밋·업로드·배포 전이다.
- 배포 후 확인: 실제 서버 지역, 홈·복지·뉴스 응답, 로그인 추천, 오류 기록, 사진·지도, 이전 서비스워커 갱신, 동일 조건 속도 재측정.
- 사이트 전체 속도 개선 수치와 실사용자 속도 목표 달성은 아직 확정하지 않는다.
- 기존 운영 수집 조사 파일 세 개와 비밀번호 파일은 이번 변경에 포함하지 않는다.
