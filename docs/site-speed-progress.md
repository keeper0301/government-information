# 사이트 속도 개선 작업 기록

계획: ../keepio_agent/docs/reports/2026-10-06-site-speed-plan.md

기준 코드: 725b22eb

## 작업 순서

1. 공개 조회 분리, 비로그인 추천 조회 제거, 사진과 미리 읽기 조정.
2. 공통 통계와 목록의 단기 재사용, 홈 상단 먼저 표시, 가이드 조회 제한.
3. 초기 실행 파일 분석, 저장 전략 수정, 저장소와 서버 위치 실측.
4. 관련 검사, 전체 코드 검사와 빌드, 별도 코드 검토, 변경 후 속도 비교.

## 판단 기록

- 개인화 목록 전체 화면은 공통 저장하지 않고 공개 자료 조회 결과만 재사용한다.
- 가이드 본문 변경 직후 검수 판정이 달라져야 하므로 가이드 검수 결과는 요청 간 저장하지 않는다. 검수 기록이 있는 주소만 조회해서 전체 조회를 줄인다.
- 승인 범위는 개선 구현과 검사다. 변경 내용을 보고한 뒤 기존 커밋 전 확인 절차를 적용한다.
- 기존 운영 조사 파일 세 개는 이번 변경에 포함하지 않는다.

## 검사 기록

- 1단계 완료: 비로그인 추천 조회 제거, 목록 표시 항목 제한, 많은 링크의 미리 읽기 제한, 뉴스 사진 작은 파일 생성.
- 2단계 완료: 공개 조회 전용 연결, 공통 통계·목록 60초 재사용, 홈 고정 안내 먼저 표시, 가이드 검수 대상만 조회.
- 3단계 완료: 오류 기록 도구 지연 읽기, 정적 파일만 저장하는 서비스워커, 운영 저장소 최신 수집 조회 색인 3개 적용, 공개 페이지 서울 실행 지역 설정.
- 최종 전체 검사: 527개 검사 파일 통과, 4개 제외. 개별 검사 3,272개 통과, 18개 제외, 실패 0개.
- 배포용 빌드, 변경 파일 코드 형식 검사, 자료형 검사 통과.
- 별도 코드 검토에서 발견한 추천 카드 표시 항목 누락, 오프라인 대체 화면 누락, 저장 실패 시 정상 응답 중단을 수정하고 회귀 검사 통과.
- 브라우저에서 휴대폰 너비 홈·지역 지도·서울 목록 이동·뉴스 사진·사진 출처 확인.
- 느린 휴대폰 조건의 로컬 홈 1회 측정: 첫 내용 표시 1.324초, 문서 읽기 완료 4.218초. 운영 사이트와 환경이 달라 개선 비율로 해석하지 않는다.
- 저장소 최신 뉴스 조회: 색인 전 125.42밀리초, 적용 직후 1.68밀리초. 반복 조회 0.098밀리초. 개별 조회 결과이며 전체 사이트 응답 시간은 아니다.
- 운영 사이트 배포 후 지역 설정 실제 반영, 오류 기록, 로그인 추천, 동일 조건 속도 재측정은 남아 있다.
- 추가 적대적 검토에서 잘못된 페이지 번호와 브라우저 저장소 접근 실패를 수정했다. 수정 전 검사 실패와 수정 후 관련 검사 22개 통과를 확인했다.
- 사용자가 최종 검토 후 수정·커밋·업로드·배포를 명시적으로 승인했다. 기존 운영 조사 파일 세 개는 이번 변경에서 제외한다.
